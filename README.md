# Проектирование и разработка программно-аппаратного комплекса персонализированного мониторинга и коррекции состояния здоровья на основе биометрических данных

Репозиторий содержит исходные файлы пояснительной записки (ПЗ) и графических материалов курсового проекта по направлению подготовки 09.03.01 «Информатика и вычислительная техника» (Кафедра электронных вычислительных машин, Вятский государственный университет).

* **Шифр документа:** ТПЖА.090301.838 ПЗ
* **Стандарты оформления:** Текст пояснительной записки оформлен в издательской системе LaTeX в соответствии с требованиями стандарта предприятия СТП ВятГУ 102-2004 и государственного стандарта ГОСТ 19.404-79. Оформление рамок и штампов выполнено с помощью пакета eskdx.

---

## Описание проекта

Проект представляет собой интегрированный программно-аппаратный комплекс для непрерывного мониторинга и коррекции физиологических показателей пользователя. В состав комплекса входят четыре основные подсистемы:

1. **СОМАТОПОС** — модуль сбора и первичной фильтрации биосигналов (частота сердечных сокращений, электромиограмма, электроэнцефалограмма, кожно-гальваническая реакция) на базе микроконтроллера ESP32-S3.
2. **Интерны** — серверная подсистема на базе СУБД SQLite для хранения сессий мониторинга и обеспечения ролевого доступа пользователей (пациент, врач, администратор).
3. **Код Здоровья** — подсистема классификации функционального состояния пользователя с помощью алгоритмов машинного обучения (Random Forest) и видеоанализа суставных углов при выполнении лечебной физкультуры (библиотека MediaPipe Pose).
4. **Чумной Доктор** — интерфейс командной строки для администрирования системы и сценарии развертывания.

## Инструкция по сборке документов

Для компиляции документов в формат PDF требуется установленный дистрибутив LaTeX (например, TeX Live) и утилита сборки latexmk.

Поскольку для подсветки исходного кода программных модулей используется пакет minted, компиляцию необходимо запускать с флагом `-shell-escape` и предусмотреть наличие в системе интерпретатора Python с установленной библиотекой Pygments.

### Команды для сборки:

1. **Компиляция пояснительной записки (main.pdf):**
   ```bash
   latexmk -pdf -shell-escape main.tex
   ```

2. **Компиляция плакатов графической части (graphics.pdf):**
   ```bash
   latexmk -pdf -shell-escape graphics.tex
   ```

3. **Очистка каталога от промежуточных файлов сборки:**
   ```bash
   latexmk -c
   ```
